# GPT Rewards Platform

This repository contains the initial production-ready foundation for a GPT rewards platform inspired by modern reward SaaS products.

Phase 1 implemented:
- Next.js + TypeScript app foundation
- Tailwind CSS setup
- SQLite-ready data layer
- Auth flow shell and dashboard shell
- Admin shell
- Demo seed preparation
- Database schema and user model structure

Next phases to complete:
1. Real SQLite user/auth persistence
2. Dashboard data and wallet ledger
3. Offer engine and reward logic
4. Offerwall, surveys, and posting logic
5. Referral, leaderboard, and levels
6. Shop, withdrawals, support, and admin management
7. Security, fraud rules, and error handling
8. Production deployment guide

Important:
This is an incremental build. The project is being created in development phases, not as a fake prototype.
